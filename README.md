# Discord Emoji Bot

카카오 이모티콘 주소를 넣으면 디스코드에서 `/e 이름`으로 바로 보낼 수 있게 해 주는 봇과 관리자 웹입니다.
지인끼리 쓰는 소규모 서버를 전제로 만들었습니다.

- 봇: `/e` 명령 하나로 보내기, 팩 추가, 단일 추가, 검색, 삭제
- 관리자 웹: 대시보드, 이모티콘·그룹·태그 관리, 디스코드 유저 권한(봇 사용 / 웹 사용), 관리자 계정 변경
- 이미지는 긴 변 180px로 맞춰 저장하고, 움직이는 이모티콘은 GIF로 변환합니다.

## 1. 설치 전 준비 (디스코드 개발자 포털)

1. https://discord.com/developers/applications 에서 **New Application**을 만듭니다.
2. **Bot** 메뉴에서 **Reset Token**을 눌러 토큰을 복사해 둡니다. 특권 인텐트(Privileged Gateway Intents)는 켜지 않아도 됩니다.
3. **Installation** 메뉴의 Installation Contexts에서 **User Install**과 **Guild Install**을 모두 켭니다.
   User Install이 켜져 있어야 1:1 DM에서도 봇을 쓸 수 있습니다.

## 2. 설치 (Ubuntu 26.04)

```bash
git clone https://github.com/<계정>/emoji-bot.git
cd emoji-bot
sudo ./install.sh
```

스크립트가 묻는 것은 봇 토큰, 관리자 웹 포트(기본 8080), **외부 접속 주소**, **이모티콘 이미지 저장 폴더**(기본 `/var/lib/emoji-bot/images`), 관리자 아이디·비밀번호입니다.
외부 접속 주소는 디스코드에 보내는 링크(갤러리, `/e web`)에 쓰입니다. 폰에서도 열리게 하려면 도메인을 넣으세요(아래 '도메인과 HTTPS').
비밀번호를 비워 두면 자동 생성해서 마지막에 한 번만 보여줍니다.
다시 실행해서 이미지 폴더를 바꾸면 기존 이미지를 새 폴더로 복사합니다(원래 폴더는 남겨 둡니다).

설치가 끝나면 두 서비스가 `enable` 상태로 바로 실행됩니다.

| 서비스 | 역할 |
| --- | --- |
| `emoji-bot.service` | 디스코드 봇 |
| `emoji-web.service` | 관리자 웹 (gunicorn) |

마지막 화면에 나오는 링크로 봇을 서버에 초대하거나 내 계정에 설치하세요.

### 도메인과 HTTPS (폰에서 갤러리를 열려면 필요)

1. 도메인(또는 DDNS)이 공유기의 공인 IP를 가리키게 하고, 공유기에서 80·443 포트를 이 VM으로 포트포워딩합니다.
2. VM에 Caddy를 설치하고 `/etc/caddy/Caddyfile`을 아래처럼 씁니다. 인증서는 자동으로 발급됩니다.
   ```
   emoji.example.com {
       reverse_proxy 127.0.0.1:8080
   }
   ```
   ```bash
   sudo apt install -y caddy && sudo systemctl reload caddy
   ```
3. `sudo bash install.sh`를 다시 실행해 외부 접속 주소에 `https://emoji.example.com`을 넣습니다.
   https 주소를 넣으면 프록시가 알려주는 실제 접속 IP를 쓰도록 자동 설정됩니다(로그인 잠금이 모든 사람에게 걸리는 문제 방지).
4. 공유기에서 8080 포트는 포트포워딩하지 마세요. 밖에서는 443(HTTPS)으로만 들어오게 합니다.

### 처음 쓰는 순서

1. 디스코드에서 `/e help`를 한 번 입력합니다. 이때 유저가 **권한 없이** 등록됩니다.
2. 관리자 웹 → **디스코드 유저**에서 `봇 사용`(필요하면 `웹 사용`)을 체크합니다.
3. `/e add-pack`을 골라 카카오 주소와 팩 이름을 넣고, `/e find`로 갤러리를 열어 봅니다.

## 3. 봇 명령어

디스코드에서 `/e`를 입력하면 아래 하위 명령이 목록으로 뜹니다. 고르면 채울 칸이 이름과 설명과 함께 차례로 나오고, 대부분 자동완성이나 선택지로 고를 수 있습니다.

| 명령 | 입력 칸 | 설명 |
| --- | --- | --- |
| `/e send` | 이모티콘 | 이름·팩 이름·태그 일부를 입력하면 자동완성 목록에서 골라 바로 보냅니다. 비워 두면 많이 쓴 순서로 나옵니다. |
| `/e find` | 검색어, 기준 | **웹 갤러리 링크**가 나만 보이게 뜹니다. 폰·PC 브라우저에서 팩별로 묶인 이미지를 스크롤하며 보고, 누르면 이 채널(DM 포함)에 바로 보내집니다. 갤러리 안에서 다시 검색하고 기준(전체·이름·태그·그룹)과 팩으로 거를 수 있습니다. 링크는 14분 동안, 명령을 쓴 본인만 쓸 수 있습니다. |
| `/e add-pack` | 카카오주소, 팩이름 | 팩을 통째로 추가합니다. 이모티콘마다 `팩이름-1`, `팩이름-2` … 이름이 붙고, 끝나면 추가된 팩의 갤러리 링크를 줍니다. |
| `/e add` | 이모티콘이름, 이미지, 이미지주소, 이름, 그룹, 태그 | 이미지 1개를 추가합니다. 그룹·태그는 **등록된 것만** 자동완성으로 고를 수 있고, 쉼표로 여러 개 이어서 고를 수 있습니다. |
| `/e del-pack` | 기준, 값 | 이름·태그·그룹 중 기준을 고르면 값 칸에 해당 목록이 나옵니다. 확인 버튼을 누르면 모두 삭제합니다. |
| `/e del` | 대상, 값 | 이모티콘 1개 삭제, 또는 태그·그룹 이름만 삭제(이모티콘은 남음). |
| `/e web` | 없음 | 관리자 웹 로그인 링크 (웹 사용 권한 필요, 10분 동안 한 번만 사용 가능). |
| `/e help` | 없음 | 사용법 |

- 이름 규칙: 공백 없이 1~40자(한글, 영문, 숫자, `_`, `-`).
- 새 태그·그룹은 관리자 웹에서만 만듭니다. 디스코드에서 없는 이름을 입력하면 추가되지 않고 안내가 나옵니다.
- 채널에는 이모티콘만 남고, 안내·링크는 **나만 보이는 메시지**로 뜹니다. 완료 안내는 20초 뒤 사라집니다.
- 디스코드 자동완성 목록에는 이미지를 넣을 수 없어서, 생김새는 `/e find` 갤러리로 확인합니다.
- 갤러리 링크가 14분인 이유: 디스코드가 명령을 쓴 뒤 15분 동안만 그 채널에 이어서 보내는 것을 허용하기 때문입니다.

## 4. 관리자 웹

- **대시보드**: 등록 이모티콘(총·오늘 신규·오늘 삭제), 디스코드 유저 현황, 오늘 등록한 이모티콘, 하루·일주일·한 달 사용 순위
- **이모티콘**: 검색, 팩 추가(URL), 단일 추가(파일 선택·끌어놓기·Ctrl+V 붙여넣기·URL), 이름 변경, 삭제
  - 기본 정렬은 No 1번부터. 열 제목을 누르면 그 기준 내림차순, 한 번 더 누르면 오름차순
  - 팩 행을 누르면 이미지·이모티콘 이름·태그가 펼쳐집니다.
  - 그룹·태그를 누르면 **등록된 목록에서 체크해서 고르는** 창이 뜹니다(여러 개 가능). 찾기 칸에 없는 이름을 쓰면 '새로 만들기' 버튼이 나오고, 눌러야만 새로 생깁니다.
- **그룹 / 태그**: 목록, 검색, 추가, 이름 변경, 삭제, 속한 개수
- **디스코드 유저** (관리자 계정만): 권한 체크 즉시 적용, ID로 직접 추가, 삭제
- **계정** (관리자 계정만): 관리자 아이디·비밀번호 변경

디스코드 유저는 `/e web` 링크로 들어오며, 유저 관리와 계정 메뉴는 보이지 않습니다.

## 5. 운영

```bash
journalctl -u emoji-bot -f          # 봇 로그
journalctl -u emoji-web -f          # 웹 로그
sudo systemctl restart emoji-bot emoji-web

# 코드 업데이트: 다시 받은 뒤 설치 스크립트 재실행 (토큰·DB·이미지·계정 유지)
git pull && sudo ./install.sh

# 관리자 비밀번호 초기화
cd /opt/emoji-bot && sudo -u emojibot bash -c 'set -a; . /etc/emoji-bot/emoji-bot.env; set +a; \
  exec .venv/bin/python -m emojibot.admin --reset'
```

| 경로 | 내용 |
| --- | --- |
| `/opt/emoji-bot` | 프로그램 |
| `/etc/emoji-bot/emoji-bot.env` | 봇 토큰, 세션 키, 포트 등 설정 (root:emojibot, 640) |
| `/var/lib/emoji-bot/emoji.db` | 데이터베이스 (SQLite) |
| 설치 때 고른 폴더 (기본 `/var/lib/emoji-bot/images/`) | 변환된 이모티콘 이미지 |

백업은 `/var/lib/emoji-bot` 폴더와 이미지 폴더를 복사하면 됩니다. 봇 토큰은 저장소에 올라가지 않습니다.

검증 스크립트: `python3 tests/check.py` (네트워크 없이 파싱, 이미지 변환, 추가·검색·삭제 흐름 확인)

## 6. 알아둘 점

- 설치 콘솔에서 한글이 깨지면(Proxmox noVNC 등) SSH로 접속해서 설치하세요.
- 1:1 DM에서는 봇(앱) 이름으로 출력되고, 메시지 위에 "○○님이 /e 사용" 표시가 붙습니다. 디스코드 구조상 바꿀 수 없습니다.
- 카카오 페이지 구조가 바뀌면 `add-pack`이 실패할 수 있습니다. 수집 로직은 `emojibot/core.py`의 `parse_kakao` 한 곳에 있습니다.
- 카카오 상세 페이지가 움직이는 이모티콘을 정지 미리보기로만 제공하는 경우 정지 이미지로 저장될 수 있습니다. 실제 팩으로 한 번 확인이 필요합니다.
- 관리자 웹 자체는 HTTP입니다. 외부에 공개할 때는 반드시 위의 HTTPS 프록시를 거치게 하세요.
- 수집한 이미지는 작가와 카카오의 저작물입니다. 지인 간 소규모 사용 범위를 넘기지 않도록 주의하세요.
